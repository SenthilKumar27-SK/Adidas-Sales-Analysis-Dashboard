# 🚀 Adidas Sales Analysis Dashboard using Power BI

## 📌 Overview

This project analyzes Adidas sales data using Power BI to uncover key insights related to revenue, profit, product performance, and regional trends.
The dashboard transforms raw data into interactive visualizations for better decision-making.

---

## 📊 Dashboard Preview

![Adidas Sales Dashboard](https://raw.githubusercontent.com/SenthilKumar27-SK/Adidas-Sales-Analysis-Dashboard/main/images/dashboard_preview.png)

---

## 🎯 Objectives

* Analyze overall sales and profit performance
* Identify top-performing regions and products
* Compare sales channels (Online, Outlet, In-store)
* Track seasonal sales trends

---

## 🔍 Key Insights

* 💰 Total Sales: **$120M+**
* 📈 Total Profit: **$47M+**
* 👟 Top Category: **Street Footwear**
* 🌎 Top Regions: **New York, California**
* 🛒 Best Sales Channel: **Online**
* 📊 Highest Sales observed in **Q3**

## 📂 Dataset Description

The dataset contains:

* Retailer, Region, State, City
* Product Category & Gender
* Sales Method (Online, Outlet, In-store)
* Units Sold, Price per Unit
* Total Sales and Profit
* Time Period (Year, Quarter)

---

## 📊 Dashboard Features

* KPI Cards (Sales, Profit, Units Sold, Avg Price)
* Sales by Product Category
* Profit by Retailer
* Sales by State and City
* Sales by Channel
* Quarterly Trends
* Interactive Filters (Year, Region, City)

---

## ▶️ How to Use

1. Download the `.pbix` file from the dashboard folder
2. Open it in Power BI Desktop
3. Use filters to explore insights
